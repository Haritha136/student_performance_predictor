AI Student Performance Predictor

Project Overview

An educational machine-learning web application that predicts a student's performance category using study hours, attendance percentage, and previous exam score.

Technologies Used

- Python
- Streamlit
- Pandas
- Scikit-learn
- Decision Tree Classifier

Features

- Interactive input sliders
- Machine-learning-based predictions
- Simple web interface
- Model training and evaluation

How to Run

1. Install Python.
2. Install the required libraries:
   "python -m pip install streamlit pandas scikit-learn matplotlib"
3. Train the model:
   "python train_model.py"
4. Start the application:
   "python -m streamlit run app.py"

Dataset

The project currently uses a small, artificially created sample dataset for demonstration. Its predictions and accuracy are not suitable for real student assessment.
